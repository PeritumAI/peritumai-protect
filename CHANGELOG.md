# Changelog

All notable changes to PeritumAI Protect are listed here. Versions follow [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-11-13

First public release.

- Clipboard check for text, HTML, RTF and pictures (Windows OCR), with Redact, Stop and Ignore.
- File and folder check for txt, md, csv, json, xml, log, html, docx, xlsx, pptx (and macro variants), pdf, eml, zip and images.
- Protected copy, reversible copy with local restore, Clean for sharing, and AI bundle export.
- Suspicious link check for copied links and for links in emails and documents, with "Sites I use".
- Profiles (General, Lawyer, Clinic/Health, Accountant/Finance, HR, Developer, Journalist) and 16 country ID packs.
- Organization policy through `policy.json` or the registry.
- English user interface.
